# Actuator line smearing correction

This repository contains implementations of a vortex-based
smearing correction for actuator line (AL) forces. Gaussian force smearing
reduces the vorticity shed by the actuator line and therefore underpredicts
the induced velocity. The routine estimates the missing near-wake induction
and uses it to correct the angle of attack and aerodynamic forces.

The implementation follows the fast method of Meyer Forsting et al. (2020),
based on the correction of Meyer Forsting et al. (2019). It supports 3D swept
and pre-bent blade geometries and includes the near-wake model and coordinate
transformations in the source file.

The original, host-integrated Fortran implementation is
[`al_nw_smearing_correction.f`](./al_nw_smearing_correction.f). Language
translations and tests are available in [`code_translations/`](./code_translations/)
for Python, MATLAB, free-form Fortran, and C++. They were generated by Claude and cross-checked against the original.

## Integration and use

The code is intended to be called from an existing AL/CFD solver; this
repository contains the correction source and license, not a complete host
solver or standalone build setup. The source uses host-provided `params`,
`ns_contr`, and `TurbineData` modules for precision, simulation state, and
project information.

1. Set the module variable `kaya` to `.true.` to activate the correction.
2. Call `init_nw_smearing_correction(n_rotors_in, n_blades_in,
   n_sections_in)` once, after enabling the correction and before calling the
   correction routine. It allocates the history and geometry arrays and
   initializes the output files.
3. Call `nw_smearing_correction(...)` for each blade, supplying that blade's
   current geometry, CFD velocities, and airfoil data.
4. If blade deformation changes the geometry substantially, set
   `kaya_refresh(i,j)` to `.true.` for the affected rotor and blade so that
   geometry-dependent constants are recalculated.

As recommended in the source documentation, activate the correction only
after the starting vortex has travelled at least one blade length downstream
of the rotor. Set `nw_max_resid` to the desired convergence tolerance; its
default is `1e-6`.

## Main routine

`nw_smearing_correction(i, j, len_2d, ..., Fstn)` computes the correction
for one blade. Here `i` and `j` are the rotor and blade indices. The main
inputs are:

| Input | Meaning |
| --- | --- |
| `len_2d` | Number of samples in the airfoil coefficient curves. |
| `cyl_cp(n_s,3)` | Control-point positions in the rotor cylindrical frame. |
| `cyl_vtp(n_v,3)` | Vortex trailing-point positions in the rotor cylindrical frame. |
| `vstn_cfd(n_s,3)` | CFD velocities at control points in the local section frame. |
| `vcyl_cfd(n_s,3)` | CFD velocities at control points in the rotor cylindrical frame. |
| `eps_cp` | Gaussian smearing length scale. |
| `omega` | Rotor angular speed in radians per second. |
| `chord(n_s)`, `twist(n_s)` | Chord and twist distributions at control points. |
| `pitch` | Blade pitch in degrees; positive is toward feather. |
| `cl_2d(len_2d,n_s)`, `cd_2d(len_2d,n_s)` | Lift and drag coefficient curves at each control point. |
| `alpha_2d(len_2d,n_s)` | Angle values corresponding to the coefficient curves. |
| `cone` | Rigid blade coning angle in degrees; positive is upstream. |
| `fbend(n_s)` | Local out-of-plane bending angles in degrees; positive is upstream. |
| `sweep(n_s)` | Local in-plane sweep angles in degrees; positive is in the direction of rotation. |
| `dsweep(n_s)` | Difference between local sweep and root-based sweep, in degrees. |
| `l1point` | Enables the unsteady angle of attack correction for curved blade trajectories. |
| `lgammafilter` | Enables time filtering of circulation. |

The routine returns `Fstn(n_s,3)`, the aerodynamic force components at control
points in the local section frame: component 1 is spanwise, 2 tangential, and
3 normal. Force magnitudes are calculated from air density, relative wind
speed, chord, and interpolated lift and drag coefficients.

When `l1point` is enabled, the effective angle of attack for lift and drag is
evaluated at three-quarter chord, and the force projection angle at
quarter-chord, accounting for the curved trajectory of coned or bent blades.

## Coordinate conventions and geometry

The source uses two frames:

- **Local section (`stn`)**: 1 spanwise (`s`), 2 tangential (`t`, chordwise),
  3 normal (`n`, flapwise).
- **Rotor cylindrical (`cyl`)**: 1 radial (`r`), 2 azimuthal (`theta`),
  3 axial (`z`).

Position arrays `cyl_cp` and `cyl_vtp` are in the rotor cylindrical frame,
rigidly pitched and coned but independent of local sweep and bending. Velocity
arrays are supplied in both frames as specified above. The radial coordinate
is along the blade from the rotor centre; it must be ascending, and the first
vortex trailing point must have a positive radial position. If the first
trailing point is below `0.1`, the routine warns, switches `kaya` off, and
returns.

The local sweep and bending angles are derived from section-to-section changes
in blade curve length and tangential/normal displacement. Their sign
conventions and formulas are documented alongside the routine arguments in
`al_nw_smearing_correction.f`.

## Module variables

The `nw_smearing_correction_module` holds the switches, dimensions,
configuration, cached geometry terms, and previous-time-step state.

| Variable | Purpose |
| --- | --- |
| `kaya` | Global correction on/off switch; initialized to `.false.`. |
| `kaya_refresh(n_rotors,n_blades)` | Per-rotor/blade flag requesting recomputation of geometry-dependent terms. |
| `n_rotors`, `n_blades` | Numbers of rotors and blades. |
| `n_s` | Number of blade sections/control points. |
| `n_v` | Number of vortex trailing points; initialized as `n_s + 1`. |
| `nw_max_resid` | Convergence tolerance for the induced-velocity residual; default `1e-6`. |
| `x_aoa` | Chordwise location used for the angle of attack computation; default `0.5`. |
| `cp_loop_ind` | Per-vortex-point lower and upper control-point indices to evaluate. |
| `nw_phi`, `nw_phi_s`, `nw_dx`, `nw_dy`, `nw_a`, `smear_fac` | Cached near-wake and smearing terms, recomputed when geometry is refreshed. |
| `nw_W_history`, `nw_vn_history`, `nw_vt_history` | Previous-step induced-velocity history. |
| `nw_Gamma_history`, `nw_dyn_comp_history` | Previous-step circulation and dynamic-filter state. |
| `nw_X_history`, `nw_Y_history` | Previous-step slow and fast near-wake induction components. |

Variables ending in `_history` retain state across time steps and are stored
for all rotors and blades. The module also defines fixed circulation-filter
and near-wake model constants from the cited publications.

## Initialization, iteration, and output

`init_nw_smearing_correction` allocates and zero-initializes the module arrays
for the requested rotor, blade, and section counts. It sets `n_v` to one more
than `n_s` and marks all rotor/blade geometry for refresh. Initialization
returns without allocating arrays if `kaya` is false.

The main routine computes the near-wake induction iteratively, updating
circulation, velocities, and angles of attack until the residual is below
`nw_max_resid`. Iteration is capped at 500 sub-iterations. If the limit is
reached without convergence, the routine falls back to the previous
time-step's near-wake state.

On processor 1, initialization opens one formatted output file for each
rotor/blade pair, using the project name followed by `.nwXX.blXX`. The main
routine writes the simulation time, iteration count, residual, CFD and
corrected angles of attack, trailing-point flow angles, induced velocities,
circulation changes, and elapsed time.

## Routines in the source

- `nw_smearing_correction`: Main per-blade correction and force calculation.
- `init_nw_smearing_correction`: Allocate and initialize state and output.
- `smearing_factor`: Evaluate the Gaussian smearing contribution.
- `nw_hr_components`, `nw_phi_components`, `nw_XY_components`: Build the
  geometric and flow-dependent near-wake model components.
- `nw_circulation`: Interpolate airfoil lift data and calculate bound and
  shed circulation, optionally applying the circulation response filter.
- `nw_calc_relax`: Estimate the iteration relaxation factor.
- `nw_interp1d`: Linear interpolation with endpoint extrapolation.
- `nw2vstn`, `Vxyz_Vstn`, and the rotation helpers: Transform velocities
  between cylindrical and local blade-section frames.
